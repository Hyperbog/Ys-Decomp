# Whole-System Milestone 7 — seven independently source-backed physical banks

**Seven complete 16-KiB banks:** physical 0, 1, 2, 3, 4, 6, 7. This means **114,688 bytes in seven complete source-only bank images**; partial data source in other banks raises cartridge-wide source ownership to **115,009 / 262,144 bytes (43.8725%)**. Original-ROM fallback: **147,135 bytes** in nine incomplete banks.

Bank 4 adds **16,222 source-generated bytes** from patterned four-byte lanes, explicitly unresolved trailer, and padding. Only its existing 124-byte rectangle descriptor directory and 38-byte Z80 routine have substantiated consumer semantics. No new executable bytes are claimed in this phase. Source-backed != fully reverse engineered. In particular, the graphics format and large portions of banks 1 and 2 remain unresolved. See `wholebank04/README.md`.

**Integrated collision evidence:** bank-1 call instructions at `$47C2`, `$486C`, `$48DF` target bank-4 CPU `$807C`. The call path is statically linked and the latter routine has 3,968 synthetic-state bounded executions checked against an independent field-level predicate. Actual cartridge mapper state at the call sites remains unproven, so this is not gameplay-validation evidence.

`tools/build_system_m7.py` emits all seven source-only banks with **no original ROM**, and uses the supplied original ROM only as fallback for the other nine during 256-KiB overlay verification. The complete output is compared against the owner original and SHA-256. `tools/wla_system_m7.py` prepares WLA-DX fixtures; external assembler/linker execution is still unverified.

This milestone prioritizes source-only whole-bank reconstruction and end-to-end subsystem evidence, not isolated byte-count claims. The **remaining nine physical banks** are 5, 8, 9, 10, 11, 12, 13, 14, and 15. A source-only full cartridge and independently assembled/reproduced gameplay remain future milestones.
